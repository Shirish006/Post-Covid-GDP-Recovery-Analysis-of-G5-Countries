GDP Growth Rate Queries
Q1 GDP Growth
Retrieves GDP growth rates for all G5 countries across all available years, ordered by country and year.
SELECT c.country_name, g.year, g.gdp_growth_rate
FROM   gdp_growth g
JOIN   g5_countries c ON g.country_name = c.country_name
ORDER BY c.country_name, g.year;
Q2 GDP Growth
Shows GDP growth rates for 2020 (COVID shock year) sorted ascending — the most severely impacted country appears first.
SELECT c.country_name, g.gdp_growth_rate
FROM   gdp_growth g
JOIN   g5_countries c ON g.country_name = c.country_name
WHERE  g.year = 2020
ORDER BY g.gdp_growth_rate ASC;
Q3 GDP Growth
Shows 2021 GDP growth rates in descending order to highlight which G5 economy rebounded the strongest post-lockdown.
SELECT c.country_name, g.gdp_growth_rate
FROM   gdp_growth g
JOIN   g5_countries c ON g.country_name = c.country_name
WHERE  g.year = 2021
ORDER BY g.gdp_growth_rate DESC;
Inflation Rate Queries
Q4 Inflation
Retrieves complete inflation history for all G5 countries, ordered by country name and year.
SELECT c.country_name, i.year, i.inflation_rate
FROM   inflation i
JOIN   g5_countries c ON i.country_name = c.country_name
ORDER BY c.country_name, i.year;
Q5 Inflation
Ranks G5 countries by inflation rate in 2022 from highest to lowest.
SELECT c.country_name, i.inflation_rate
FROM   inflation i
JOIN   g5_countries c ON i.country_name = c.country_name
WHERE  i.year = 2022
ORDER BY i.inflation_rate DESC;
Unemployment Rate Queries
Q6 Unemployment
Retrieves the full unemployment timeline for all G5 countries, grouped by country and sorted chronologically.
SELECT c.country_name, u.year, u.unemployment_rate
FROM   unemployment u
JOIN   g5_countries c ON u.country_name = c.country_name
ORDER BY c.country_name, u.year;
Q7 Unemployment
Ranks G5 countries by unemployment rate in 2024 — lowest unemployment appears first.
SELECT c.country_name, u.unemployment_rate
FROM   unemployment u
JOIN   g5_countries c ON u.country_name = c.country_name
WHERE  u.year = 2024
ORDER BY u.unemployment_rate ASC;
Absolute GDP Value Queries
Q8 GDP Value
Returns the complete absolute GDP value dataset for all G5 nations across all recorded years.
SELECT c.country_name, v.year, v.gdp_value
FROM   gdp_value v
JOIN   g5_countries c ON v.country_name = c.country_name
ORDER BY c.country_name, v.year;
Q10 GDP Value
Ranks G5 economies by absolute GDP value in 2024 from the largest to the smallest.
SELECT c.country_name, v.gdp_value
FROM   gdp_value v
JOIN   g5_countries c ON v.country_name = c.country_name
WHERE  v.year = 2024
ORDER BY v.gdp_value DESC;
